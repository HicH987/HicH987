## Now, at Kipful

- **The platform.** Customer dashboard in English, French and Dutch, public profiles with Apple and Google Wallet passes, back office and print studio. More than 3,000 companies use it.
- **AI theme engine.** Gemini through OpenRouter. The LLM picks the style and lays out the sections, the server validates and applies the result. Output is constrained JSON, so a prompt injection can only ever produce a short chat bubble.
- **Integrations.** Outlook add-in for email signatures, nightly sync of Microsoft Entra directories and CRM leads (HubSpot, Salesforce, Odoo).
- **Infrastructure.** AWS (Amplify, ECS Fargate, Lambda, EventBridge, S3, CloudWatch), Keycloak for identity, GitHub Actions with OIDC for every deploy.

The code is private. The [case study](https://hich987.vercel.app/en/work/kipful/) covers what I built and how.
